# Jetson Cam Project

Real-time object detection on an NVIDIA Jetson Orin Nano Super, using a
Logitech HD 720p Autofocus USB webcam.

## Hardware
- NVIDIA Jetson Orin Nano Super Developer Kit
- Logitech HD 720p Autofocus USB Webcam

## Status
- [x] Jetson flashed (JetPack 7.2.1), SSH + IntelliJ Remote Dev connected
